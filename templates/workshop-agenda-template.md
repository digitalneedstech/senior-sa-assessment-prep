# Architecture Assessment Workshop — Agenda

**Case:** [Name]   **Duration:** [e.g. 60 min]   **Date:** [ ]

| Time | Segment | Goal |
|---|---|---|
| 0:00–0:03 | Opening framing | Restate problem, confirm scope, state key assumptions |
| 0:03–0:08 | Architecture v1 — Context view | Zoomed-out narrative, invite first reactions |
| 0:08–0:28 | Deep dive — top 2-3 decisions | Defend via ADR technique (context → decision → alternatives → consequences) |
| 0:28–0:45 | Scenario stress-tests | Respond live to panel "what-if" scenarios |
| 0:45–0:55 | Live refinement | Update diagram based on discussion |
| 0:55–1:05 | Costing walkthrough | Present cost band tied to refined diagram, top optimization lever |
| 1:05–1:08 | Close | Summarize decisions, open risks, "if I had another week..." |

### Pre-workshop checklist
- [ ] v1 architecture diagram ready (context + container view minimum)
- [ ] ADRs drafted for top 3 riskiest decisions
- [ ] Cost band calculated with named swing factor
- [ ] Assumptions register printed/pinned for quick reference
- [ ] Opening framing statement rehearsed (30 seconds, no notes)
